# 📊 Sales Analysis Dashboard — Power BI

## 📌 Project Overview

An interactive **Sales Analysis Dashboard built with Power BI** to analyze sales performance and transform raw sales data into clear, actionable business insights.

## 🎯 Project Objectives

* Track **Revenue, Cost, and Profit**
* Analyze sales performance by **product, region, and sales channel**
* Identify sales trends over time
* Monitor units sold and overall performance
* Create an interactive dashboard for easier business decision-making

## 🛠️ Tools Used

* **Power BI**
* **Power Query**
* **DAX**

## 📊 Key Metrics

* Total Revenue
* Total Cost
* Total Profit
* Units Sold
* Sales Performance
* Regional Performance
* Product Performance
* Sales Channel Performance

## 🔍 Analysis Performed

The dashboard provides insights into:

* Revenue and profit trends
* Cost and profitability
* Regional sales performance
* Product/item performance
* Sales channel performance
* Units sold and overall sales activity

Interactive filters and visualizations allow users to explore different aspects of the sales data.
